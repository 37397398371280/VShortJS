How to Use ShortJS

Practical recipes, patterns, and edge-case behavior for writing, expanding, customizing, and debugging compact JavaScript with ShortJS.

1. Quick Start & Common Workflows

You can use ShortJS in three main ways depending on whether you want to inspect the generated JavaScript, execute it immediately, or transform code in a build step.

Pattern A: Expand to Standard JavaScript (ShortJS.expand)

ct jsCode = ShortJS.expand(`
  fu greet(name) {
    ct clean = name.trm().tupc();
    rt "Hello, " + clean + "!";
  }
  cl(greet("  ada  "));
`);

console.log(jsCode);
// Output:
// function greet(name) {
//   const clean = name.trim().toUpperCase();
//   return "Hello, " + clean + "!";
// }
// console.log(greet("  ada  "));

Pattern B: Expand and Execute Immediately (ShortJS.run)

ct total = ShortJS.run(`
  ct nums = [1, 2, 3, 4, 5];
  rt nums
    .flt(n => n % 2 === 1)
    .mp(n => n * 10)
    .rdc((acc, n) => acc + n, 0);
`);

console.log(total); // 90

Pattern C: Get Both Expanded Code and Line Map (ShortJS.expandWithMap)

ct { code, lineMap } = ShortJS.expandWithMap(`
  fu add(a, b) {
    rt a + b;
  }
`);
// `code` -> expanded JS string
// `lineMap` -> array mapping 0-based output lines to 1-based input lines

2. Writing Shorthand Code Effectively

  • Declarations & functions: Use ct (const), lt (let), vr (var), fu (function), af (async function), gf (function*), agf (async function*), and rt (return).
  • Control flow & errors: Use ifn (if), elf (else), sw / cs (switch / case), brk (break), cnt (continue), tryc / ctch / fnl (try / catch / finally), and thr (throw).
  • Chained methods: Put a dot before chain shorthands such as .mp (.map), .flt (.filter), .rdc (.reduce), .fnd (.find), .jn (.join), .splt (.split), and .trm (.trim).
  • Standard JS syntax stays as-is: Arrow functions (=>), destructuring ({ a, b } = obj), spread/rest (...args), optional chaining (?.), nullish coalescing (??), and private fields (#secret) are standard operators/syntax and are written directly.

3. Adding, Removing & Scoped Overrides

You can mutate the global tables with add and remove, or pass temporary overrides to a single expand, expandWithMap, or run call without polluting global state.

Permanent Additions & Removals

// Add custom standalone and chain shorthands (returns `this` for chaining)
ShortJS
  .add(
    { q1: "document.querySelector", ft: "fetch" },
    { thn0: "then" }
  )
  .remove(["vr"], ["pp"]); // Remove `vr` standalone alias and `.pp` chain alias

One-Off Overrides Per Call

ct snippet = ShortJS.expand(
  `rt db.fndById(42);`,
  { db: "databaseService" }, // extra standalone aliases for this call only
  { fndById: "findUserById" } // extra chain aliases for this call only
);
// -> "return databaseService.findUserById(42);"

4. Protecting Variable & Property Names

Because shorthand tokens are short words, a token like fl (false) or sw (switch) might match a variable or parameter you want to keep as-is. Use protect(...names) to block expansion for specific identifiers. 

ShortJS.protect("fl", "sw");

ct out = ShortJS.expand(`
  fu toggle(fl, sw) {
    ifn (sw) {
      rt !fl;
    }
    rt fl;
  }
`);
// `fl` and `sw` stay `fl` and `sw`; `fu`, `ifn`, and `rt` still expand.

ShortJS.unprotect("fl"); // Re-enable `fl` -> `false` when needed

5. Strings, Template Literals & Regexes

How Context Rules Work
  • Single & double quotes: Text inside "..." or '...' is treated as literal text and never expanded.
  • Template literals (`...`): Plain template text is untouched, while expressions inside ${...}—including nested braces like object literals—expand shorthands normally.
  • Comments: Tokens inside // line comments and /* ... */ block comments are preserved without expansion.
  • Regex literals vs. division: The scanner tracks expression boundaries (needRx) and character classes ([...]) so regex patterns like /\d+/gi or /[a-z/]+/ stay intact while division a / b still works.
ct msg = ShortJS.expand(`
  // ct inside a comment stays ct
  ct word = "rt is a keyword in text";
  ct items = ["a", "b"];
  ct info = \`Count: \${items.mp(x => x.tupc()).jn(",")}\`;
  ct re = /foo\/bar/i;
  rt info;
`);

6. Debugging & Stack Traces

When code executed via ShortJS.run(...) throws an error, ShortJS uses the recorded lineMap and mapStack(err, lineMap) to translate expanded line numbers back to the line numbers in your shorthand input. 

try {
  ShortJS.run(`
    ct ok = 1;
    fu failHere() {
      thr nw Error("Something broke");
    }
    failHere();
  `);
} catch (err) {
  console.error(err.stack);
}
Practical Tip for Large Codebases
ShortJS is great for quick scripts, personal tooling, experimentation, and compact snippets. For large multi-file production apps with strict team lint rules or complex AST transforms, prefer standard JavaScript paired with conventional build/minification tools.

7. Complete API Methods

API Signature What It Does
expand expand(code, extraA?, extraC?) Returns the expanded JavaScript string.
expandWithMap expandWithMap(code, extraA?, extraC?) Returns { code, lineMap } with expanded code and line index mapping.
run run(code, extraA?, extraC?) Expands and runs code via new Function, remapping thrown stack traces.
mapStack mapStack(err, lineMap) Rewrites :line:col entries in err.stack using lineMap.
protect / unprotect protect(...names) / unprotect(...names) Prevents or allows expansion for specific identifier names.
add / remove add(a?, c?) / remove(a?, c?) Adds or deletes entries in aliases and chainAliases.

9. Full Implementation

const ShortJS = {
  aliases: {
    fu: 'function', af: 'async function', gf: 'function*', agf: 'async function*',
    aw: 'await', rt: 'return', yld: 'yield', ct: 'const', lt: 'let', vr: 'var',
    cls: 'class', ext: 'extends', nw: 'new', th: 'this', spr: 'super',
    imp: 'import', exp: 'export', df: 'default', del: 'delete', vd: 'void', dbg: 'debugger',
    ifn: 'if', elf: 'else', sw: 'switch', cs: 'case', brk: 'break', cnt: 'continue',
    fr: 'for', wh: 'while', dw: 'do', tryc: 'try', ctch: 'catch', fnl: 'finally',
    thr: 'throw', tof: 'typeof', iof: 'instanceof', inop: 'in',
    tr: 'true', fl: 'false', nl: 'null', und: 'undefined', nanv: 'NaN', infv: 'Infinity',
    gbl: 'globalThis', cl: 'console.log', cw: 'console.warn', ce: 'console.error',
    jp: 'JSON.parse', js: 'JSON.stringify', rjs: 'JSON.rawJSON',
    sumpr: 'Math.sumPrecise', rxesc: 'RegExp.escape', fromas: 'Array.fromAsync', itcat: 'Iterator.concat'
  },
  chainAliases: {
    mp: 'map', flt: 'filter', rdc: 'reduce', fe: 'forEach', fnd: 'find', fndi: 'findIndex',
    fndl: 'findLast', sm: 'some', ev: 'every', inc: 'includes', idx: 'indexOf', lidx: 'lastIndexOf',
    slc: 'slice', spl: 'splice', jn: 'join', rv: 'reverse', srt: 'sort', flm: 'flatMap',
    psh: 'push', pp: 'pop', shf: 'shift', unsh: 'unshift', thn: 'then', cth: 'catch', fin: 'finally',
    trm: 'trim', trms: 'trimStart', trme: 'trimEnd', tupc: 'toUpperCase', tlwc: 'toLowerCase',
    rpl: 'replace', rpla: 'replaceAll', splt: 'split', sw: 'startsWith', ew: 'endsWith',
    padl: 'padStart', padr: 'padEnd'
  },
  protectedNames: new Set(),
  protect(...n) { n.flat().forEach(k => this.protectedNames.add(k)); return this; },
  unprotect(...n) { n.flat().forEach(k => this.protectedNames.delete(k)); return this; },
  add(a = {}, c = {}) { Object.assign(this.aliases, a); Object.assign(this.chainAliases, c); return this; },
  remove(a = [], c = []) { a.forEach(k => delete this.aliases[k]); c.forEach(k => delete this.chainAliases[k]); return this; },

  expandWithMap(code, extraA = {}, extraC = {}) {
    const map = { ...this.aliases, ...extraA };
    const cmap = { ...this.chainAliases, ...extraC };
    const prot = this.protectedNames;
    const rxKw = new Set(['return','throw','case','delete','void','typeof','instanceof','in','of','new','yield','await','else','do']);
    const isIdStart = c => /[a-zA-Z_$]/.test(c);
    const isId = c => /[a-zA-Z0-9_$]/.test(c);

    let out = '', i = 0, quote = null, braces = [], mode = 0, rxClass = false, needRx = true;
    const lineMap = [];
    let srcLine = 1, outLine = 1, hasLine = false;

    const pushOut = s => {
      for (const c of s) {
        if (!hasLine) { lineMap[outLine - 1] = srcLine; hasLine = true; }
        out += c;
        if (c === '
') { outLine++; hasLine = false; }
      }
    };
    const stepSrc = s => { for (const c of s) if (c === '
') srcLine++; };
    const emit = (s, raw = s) => { pushOut(s); stepSrc(raw); };

    while (i < code.length) {
      const c = code[i], n = code[i + 1] || '', p = i ? code[i - 1] : '';

      if (mode === 1) { emit(c); if (c === '
') { mode = 0; needRx = true; } i++; continue; }
      if (mode === 2) {
        if (c === '*' && n === '/') { emit('*/'); i += 2; mode = 0; }
        else { emit(c); i++; }
        continue;
      }
      if (mode === 3) {
        if (c === '\' && n) { emit(c + n); i += 2; continue; }
        if (c === '[') rxClass = true;
        else if (c === ']' && rxClass) rxClass = false;
        else if (c === '/' && !rxClass) {
          let j = i + 1;
          while (j < code.length && /[a-zA-Z]/.test(code[j])) j++;
          emit(code.slice(i, j)); i = j; mode = 0; needRx = false; continue;
        }
        emit(c); i++; continue;
      }

      if (quote && (quote !== '`' || !braces.length)) {
        if (quote === '`' && c === '$' && n === '{') { emit('${'); braces.push(1); i += 2; needRx = true; continue; }
        if (c === '\' && n) { emit(c + n); i += 2; continue; }
        emit(c);
        if (c === quote) { quote = null; needRx = false; }
        i++; continue;
      }

      if (quote === '`' && braces.length) {
        if (c === '{') braces[braces.length - 1]++;
        else if (c === '}' && --braces[braces.length - 1] === 0) { braces.pop(); emit('}'); i++; continue; }
      }

      if (c === '/' && n === '/') { emit('//'); i += 2; mode = 1; continue; }
      if (c === '/' && n === '*') { emit('/*'); i += 2; mode = 2; continue; }
      if (c === '"' || c === "'" || c === '`') { quote = c; emit(c); i++; continue; }
      if (c === '/') {
        if (needRx) { mode = 3; rxClass = false; emit('/'); }
        else { emit('/'); needRx = true; }
        i++; continue;
      }

      if (isIdStart(c) && !isId(p)) {
        let e = i + 1;
        while (e < code.length && isId(code[e])) e++;
        const tok = code.slice(i, e), after = code[e] || '';
        let exp = tok;
        if (!isId(after) && !prot.has(tok)) {
          exp = (p === '.' ? cmap : map)[tok] || tok;
        }
        pushOut(exp); stepSrc(tok);
        needRx = rxKw.has(exp);
        i = e; continue;
      }

      if (/\s/.test(c)) { emit(c); i++; continue; }
      emit(c);
      needRx = !')]}'.includes(c) && !(c === '+' && p === '+') && !(c === '-' && p === '-');
      i++;
    }

    return { code: out, lineMap };
  },

  expand(code, extraA, extraC) { return this.expandWithMap(code, extraA, extraC).code; },

  mapStack(err, lineMap) {
    if (!err?.stack || !Array.isArray(lineMap)) return err?.stack || '';
    return err.stack.replace(/:(\d+):(\d+)/g, (m, l, col) => {
      const orig = lineMap[Number(l) - 1];
      return orig ? `:${orig}:${col}` : m;
    });
  },

  run(code, extraA, extraC) {
    const { code: exp, lineMap } = this.expandWithMap(code, extraA, extraC);
    try { return new Function(exp)(); }
    catch (err) { err.stack = this.mapStack(err, lineMap); throw err; }
  }
};
